# Changelog

All notable changes to the NOX Safety-Critical Redesign document set
will be recorded here.

## Core Architecture v0.1 - 2026-11-11

### Added

- Hazard-first safety architecture
- Six-zone separation model
- Independent Safety Authority
- Explicit loss and hazard catalog
- Fundamental safety constraints
- Safe-state transition model
- Effect mediation and quarantine
- Independent evidence recording
- Zeroization Verification Evidence
- Human-exposure controls
- Preliminary safety case

Initial working engineering baseline.

- Hardware acceptance gates
- Component qualification record

Normative candidate supplement to Safety-Critical Redesign v0.1.
