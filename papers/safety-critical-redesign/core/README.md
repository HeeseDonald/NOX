# Core Architecture

This directory contains the complete NOX Safety-Critical Redesign
core architecture.

## Current Baseline

NOX Safety-Critical Redesign v0.1

## Status

Working engineering draft.

Not a deployable system.  
Not certified.  
Not an operational authorization.

## Scope

The core document defines the system boundary, hazard model, safety
constraints, zone architecture, safe-state machine, effect mediation,
zeroization model, evidence requirements, and preliminary safety case.

Hardware assurance and verification-and-validation requirements are
maintained as supplements.
