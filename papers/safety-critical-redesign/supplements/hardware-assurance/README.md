# NOX Hardware Assurance Baseline

## Current Version

Version 0.2

## Relationship

This document is a candidate normative supplement to the NOX
Safety-Critical Redesign v0.1 core architecture.

It does not replace or contain the complete core architecture.

## Scope

The supplement defines requirements for:

- Hardware component disposition
- Vendor-firmware control
- Legacy-function elimination
- Mutability control
- Remote-authority elimination
- Residual-state control
- Power, clock, and reset independence
- Debug and maintenance interfaces
- Hardware acceptance testing
- Component qualification

## Status

Working engineering draft.

Requirements have been documented but not physically implemented,
verified, validated, or certified.
