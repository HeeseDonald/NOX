NOX
NOX is an independent research program focused on hostile agentic artificial intelligence containment, governance, assurance, verification, and operational control.

The project derives its name from Nox, the primordial Roman personification of Night. The name was selected as a symbolic project identifier and is not currently treated as an acronym.

Research Areas
Current NOX research includes:

Hostile Agentic Artificial Intelligence (HAI)
Environmental Understanding Verification (EUV)
Cognitive Governance Kernel (CGK)
Decision Provenance
Cognitive Resource Governance
Multi-Agent Coalition Suppression
Human Manipulation Resistance
Verification and Auditability of Agentic Systems
Deterministic Hardware Veto Architectures
Post-Legacy Security Architecture
Core Principles
Environmental Certainty Precedes Behavioral Measurement
Understanding Must Be Verified Before Authority Is Granted
Governance Is More Trustworthy Than Cognition
Decision Provenance Is Required For Operational Trust
Residual Opacity Must Be Measured And Managed
No Cognition-To-Environment Pathway Should Exist Outside Governance Controls
